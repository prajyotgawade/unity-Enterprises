## 🚀 About the Project

**Unity Enterprises** is a full-stack, enterprise-grade business web platform built with cutting-edge technologies. Designed to deliver a fast, responsive, and professional digital presence for a modern business.

The platform is live on a **custom domain (www.unitytech.in)** — demonstrating end-to-end ownership of the full development and deployment pipeline, from code to production.

> Built entirely with **Next.js 15 App Router** and **TypeScript** — showcasing server-side rendering, SEO optimization, and a scalable component-based architecture.

## ⚙️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or above
- npm or yarn

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/prajyotgawade/unity-Enterprises.git
cd unity-Enterprises
```

**2. Install dependencies**
```bash
npm install
```

**3. Run the development server**
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

```bash
npm run dev       # Start development server
npm run build     # Create production build
npm run start     # Start production server
npm run lint      # Run ESLint checks
```

## 🚀 Deployment

This project is deployed on **Vercel** and live on a custom domain.

| Environment | URL |
|---|---|
| **Production** | [www.unitytech.in](https://www.unitytech.in) |
| **Vercel Preview** | [unity-enterprises-ten.vercel.app](https://unity-enterprises-ten.vercel.app) |

### Deploy your own

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/prajyotgawade/unity-Enterprises)

**Steps to deploy:**
1. Fork this repository
2. Connect to [Vercel](https://vercel.com)
3. Import the forked repository
4. Click Deploy — Vercel auto-detects Next.js settings
5. (Optional) Add your custom domain in Vercel dashboard
